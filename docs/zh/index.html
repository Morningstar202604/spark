为什么是 Spark

刻意做的不一样

多数 Agent 悄悄自动改文件、无条件信任工具的输出。Spark 从零重写，做的正是反面。

🛡️ 审批门

每一次 write_file、apply_patch、run_shell 都会暂停征求你同意——带按文件分组的 diff 预览。询问 / 自动编辑 / 全自动三档，保护路径永远拒绝。

🧠 Prompt Injection 防护

工具和文件输出一律当作数据，不是指令。注入特征会被检测并内联警告——文件内容不能改写 Agent 的规则。

🔒 本地语义记忆

说一句"记住 XX 是 YY"——FTS5 存本地，可选升级为真正的向量语义检索（豆包 API 或离线 BGE-M3）。零隐性模型调用。

🇨🇳 国产模型优先

DeepSeek v4 · 通义 · 智谱 GLM · Kimi K3 · 豆包 · Ollama——按 2026 现役型号调好的预设，无需折腾海外账号。

🪶 轻量是设计原则

单文件 Web 前端、一个 uvicorn 进程、零 Electron。一条 pip install，全部数据落在 ~/.spark2/ 的人可读 JSONL。

🧩 可扩展

插件就是丢进 ~/.spark2/plugins/ 的 .py 文件；MCP（stdio + Streamable HTTP）内置；插件工具照样过审批门。

功能

v0.8.0 一应俱全

多文件编辑、持久终端、子 Agent、会话分叉、代码索引、成本面板——完整工作流，一点不臃肿。

📦 多文件编辑

apply_patch 一次补丁改多个文件；审批弹窗按文件分组、可展开/折叠、带 +/- 徽标。全有或全无，内置 git 检查点回滚。

🖥️ 持久终端

UI 里嵌真实 bash PTY（xterm.js），cwd 锁定工作目录。折叠、刷新都不杀进程——重开即恢复。多 tab、自适应、随时接管输入。

👥 子 Agent

explore 只读调查员，动手前先摸清代码；general 全工具执行器，写操作照样过审批。事件内联进会话，一个取消级联全停。

🍴 分叉与并行

任意节点把会话复制成独立分支；多会话并行运行，实时"● 运行中"徽标，刷新后仍在。

🔎 代码索引

index_project / search_symbol / lint_file。Python 用标准库 ast（符号+行号），其他语言行级提取；按工作目录缓存、自动失效、全只读。

💰 成本面板

每次调用的 tokens 与估算费用按会话记录；顶栏"用量"面板带会话排行条。内置 2026-09 已核验官方价（DeepSeek 谷价、豆包方舟），可覆盖。
