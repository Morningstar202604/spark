Spark 编程助手

本地 AI 编程助手 · 审批门保护 · 记忆 · MCP · 国产模型开箱即用

1打开右上角「设置」，选一个模型服务（DeepSeek / 通义 / 智谱 / Kimi / 豆包 / Ollama），填 API Key 并保存；不填也能用「演示模式」先体验。
2在设置里把「工作目录」指向你的项目文件夹（Agent 只能在此内自由读写，之外需你确认）。
3回来点「＋ 新建会话」，描述你想做的事，例如：帮我修一下登录接口的 bug。
Enter 发送 · Shift+Enter 换行 · 写入文件与执行命令会先征求你确认

关于 Spark
Spark
本地 AI 编程助手。核心能力：审批门保护（写文件/执行命令先征求你确认）、Prompt Injection 防护、本地语义记忆、多模型路由（国产模型开箱即用）、多文件编辑（diff 审批）、内置持久终端、多 Agent（explore/general）、会话分叉、代码索引、轻量插件点、成本可观测面板。
数据都在本地：会话存 ~/.spark2/sessions/、记忆 ~/.spark2/memory/、用量 ~/.spark2/usage/、索引 ~/.spark2/codeindex/。仅在你配置 API Key 的模型服务上发生调用。
